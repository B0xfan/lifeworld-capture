# LifeWorld Capture

A pen icon in your computer's menu bar. Click it, type a thought, press Return, and it is saved in your vault. You stay in the app you were using.

LifeWorld Capture is a free companion to [LifeWorld](https://github.com/B0xfan/lifeworld). It also works on its own.

## Where a capture goes

Pick a destination at the bottom left of the capture box, or press its key:

- **Daily Note** (⌘0): a line with the time under "Quick notes" in today's daily note. The note is found and made with Obsidian's own Daily notes settings. The calendar button files it into another day.
- **Inbox** (⌘I): a new note in your inbox folder (`Inbox` to start with). The first line becomes the title.
- **Task** (⌘T): with LifeWorld, a real task note that shows on the Today page and in the Planner. Words like "call Ana friday 3pm" set the Due property and time. You can pick Today or Tomorrow, morning or afternoon, and a project. Without LifeWorld, the task is a `- [ ]` line at the end of one task list note (Tasks plugin format).
- **Your own note types**: add them in Settings, Destinations. Each one makes a new note in a folder you choose (with a tag, properties or a template), or adds a line under a heading in the daily note.

Paste, drop or attach a picture and it is saved with the capture.

## Shortcut

No shortcut is set when you install it. To open the capture box from any app with your keyboard, go to Settings, General, Global shortcut, click Record and press the keys you want.

## Manual

The [user manual](docs/LifeWorld-Capture-manual.pdf) (PDF) covers every destination, the task words, pictures and each settings tab.

## Good to know

- Computers only. Made and tested on the Mac; Windows and Linux are untested. Phones have no menu bar, so the plugin does not load there.
- It works while Obsidian is open, minimized included. When you quit Obsidian, the icon goes away until you open it again.
- The icon and the shortcut use a part of Obsidian's desktop app that plugins are not officially offered. If a future Obsidian removes it, the icon simply does not appear and nothing else is affected.
- Nothing is sent anywhere. The capture box is a small local page with no links and no remote content.

## Install

Settings, Community plugins, Browse, search for "LifeWorld Capture", then Install and Enable.
